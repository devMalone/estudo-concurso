# Atualização da versão publicada

1. No SQL Editor, execute `personal-cloud.sql`.
2. Execute `create-personal-key.sql` uma vez e guarde a chave gerada.
3. No GitHub, substitua os arquivos publicados pelo conteúdo desta pasta.
4. Feche as abas antigas do site. Abra a página com internet uma vez.
5. Em **Ajustes**, clique em **Vincular aparelho** e cole a chave. Repita no celular.

O cadastro e o login não aparecem mais no site. A chave pessoal é usada apenas para vincular seus aparelhos.

Para trazer registros locais desta versão, marque **Levar também os registros que já estão neste aparelho** ao vincular. Se já havia dados enviados pela versão anterior, use **Dados da versão anterior** no mesmo navegador antes de vincular.
